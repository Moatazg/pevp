## Initial-grid policy

The dissertation §3.3.3 starts from a 3×3 lattice on `[0.8, 1.05]²`
(9 nodes, 12 axis-aligned edges). The rebuild's default
`seed_initial_grid` produces a 5-node "+" pattern; to match the
dissertation this driver passes a custom `seed_3x3_lattice` to
`greedy_refine` via the `seed_fn` parameter (DIR-015). The greedy
refinement loop itself is unchanged — only the level-0 topology
differs.

## Reconstructed-solution semantics (DIR-016)

`surrogate-surfaces.png` mirrors the dissertation's
`Figures/Paper2/2D/FinalSolution{1,2,3}.png` family. The MATLAB
pipeline (`MainGreedyAlgorithm/Clean/ExampleAug2124NoVirt.m:1081–1141`)
constructs each band's surrogate surface via

```matlab
vq2{level}{band} = griddata(x2{level}, y2{level}, EG{level}{band}, xq2, yq2);
mesh(xq2, yq2, abs(vq2{level}{band}));
plot3(x2{level}, y2{level}, EG{level}{band}, 'ro');
```

— scattered-data interpolation of the band-matched eigenvalues at the
algorithm's own snapshot nodes onto a dense grid, plus markers at the
raw snapshot eigenvalues. **No ROM eigensolve.** The rebuild's
`plot_final_solution` reproduces this verbatim using
`scipy.interpolate.griddata(method='linear')` (Delaunay triangulation +
barycentric linear, matching MATLAB's default) on the labelled snapshot
eigenvalues from `_pipeline_band_labels`. Only the first 6 bands are
rendered — pipeline label propagation is less confident on the
highest-index bands due to Hungarian permutation composition over long
paths, the same metric-definition gap recorded above for `n_wrong_match`.

## Error-table semantics

The CSV mirrors the dissertation's Table 2D Error:

| Column | Definition |
|---|---|
| `level` | Refinement iteration (0..terminal_level) |
| `n_points` | Number of grid nodes inserted by end of this level |
| `n_subintervals` | Edges active during iteration L (= surviving `Edge.level == L` + bisected ones, recovered from `Node.level == L+1`) |
| `n_wrong_match` | Nodes whose pipeline-propagated label permutation disagrees with a truth permutation obtained by direct `cost_matrix` match against the seed midpoint |
| `n_uncertified` | Edges at this level whose verdict tuple contains anything other than `Verdict.CERTIFIED` |

**`n_wrong_match` semantic gap.** The dissertation computes
`n_wrong_match` as an internal-consistency count produced by the MATLAB
pipeline (no truth tracking). The rebuild's column compares
pipeline-propagated labels against a direct-match-to-root truth label
permutation — approximate in 2D (we do not implement a continuous 2D
band-tracker) but consistent: both labellings start from the same root.
Expect the rebuild's `n_wrong_match` to disagree with the dissertation's
column even when grid topology matches; that is a metric-definition
difference, not a tuning failure.

**`n_points` at L=0.** With the `seed_3x3_lattice` seed, `n_points = 9`
exactly. `n_subintervals` at L=0 = 12 (6 horizontal + 6 vertical),
matching the dissertation.
